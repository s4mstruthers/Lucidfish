Lucidfish — Stockfish tells you the best move; Lucidfish tells you why. It grounds an LLM in real engine analysis — evals, refutation lines, and extracted positional features like tempo, king safety, and pawn structure — so you get explanations in chess concepts instead of centipawns. Opening-aware suggestions via the Lichess Opening Explorer keep early-game advice consistent with your chosen opening's plans rather than raw engine output.
